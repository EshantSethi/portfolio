# Eshant Sethi – Portfolio

My personal portfolio website. I'm a final-year B.Tech CSE student at SRMIST and a Java / Spring Boot backend developer.

## What's inside
- About, skills, projects, experience, certifications and contact sections
- A short story for each project (problem, what I built, hardest challenge, result)
- A resume download button
- Interactive buttons, a typing title, scroll animations, count-up numbers and a scroll progress bar
- Works on phones and desktops, and respects the "reduce motion" setting

## Built with
Plain HTML, CSS and JavaScript (no frameworks).

## Hosting
Hosted on **Netlify** and deployed from this GitHub repo. Every push to `main` goes live automatically.

## Run locally
Open `index.html` in any browser.
